# IO性能测试平台部署指南

## 1. 环境要求

### 1.1 系统要求
- **操作系统**: Linux (Ubuntu 20.04 LTS 推荐) / macOS / Windows 10+
- **内存**: 最少 4GB RAM (推荐 8GB+)
- **存储**: 最少 20GB 可用空间 (推荐 50GB+)
- **网络**: 稳定的网络连接

### 1.2 软件依赖
- **Python**: 3.8+
- **Node.js**: 14+
- **MySQL**: 8.0+
- **Redis**: 6.0+
- **Git**: 2.20+

## 2. 开发环境部署

### 2.1 克隆项目
```bash
git clone https://github.com/your-org/io-performance-platform.git
cd io-performance-platform
```

### 2.2 后端部署

#### 2.2.1 创建Python虚拟环境
```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Linux/macOS
source venv/bin/activate
# Windows
venv\Scripts\activate
```

#### 2.2.2 安装依赖
```bash
pip install -r requirements.txt
```

#### 2.2.3 配置环境变量
创建 `.env` 文件：
```bash
cp .env.example .env
```

编辑 `.env` 文件：
```env
# Flask配置
FLASK_CONFIG=development
SECRET_KEY=your-secret-key-here

# 数据库配置
MYSQL_USER=root
MYSQL_PASSWORD=your-password
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DATABASE=io_platform

# Redis配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
REDIS_DB=0

# JWT配置
JWT_SECRET_KEY=your-jwt-secret-key

# 加密配置
ENCRYPTION_PASSWORD=your-encryption-password
ENCRYPTION_SALT=your-encryption-salt
```

#### 2.2.4 初始化数据库
```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS io_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 初始化数据库表
flask db init
flask db migrate -m "Initial migration"
flask db upgrade

# 创建默认管理员用户
python scripts/create_admin.py
```

#### 2.2.5 启动后端服务
```bash
# 开发模式启动
flask run --debug --host=0.0.0.0 --port=5000

# 或使用Gunicorn（生产环境）
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

### 2.3 前端部署

#### 2.3.1 安装Node.js依赖
```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 或使用yarn
yarn install
```

#### 2.3.2 配置环境变量
创建 `.env` 文件：
```env
# API配置
VUE_APP_API_BASE_URL=http://localhost:5000/api

# 其他配置
VUE_APP_APP_NAME=IO性能测试平台
VUE_APP_VERSION=1.0.0
```

#### 2.3.3 启动前端服务
```bash
# 开发模式
npm run serve

# 构建生产版本
npm run build
```

## 3. 生产环境部署

### 3.1 使用Docker部署（推荐）

#### 3.1.1 安装Docker和Docker Compose
```bash
# Ubuntu
sudo apt update
sudo apt install docker.io docker-compose-plugin

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker
```

#### 3.1.2 创建Docker Compose配置
创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  # MySQL数据库
  mysql:
    image: mysql:8.0
    container_name: io_platform_mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: your-root-password
      MYSQL_DATABASE: io_platform
      MYSQL_USER: io_user
      MYSQL_PASSWORD: your-password
    volumes:
      - mysql_data:/var/lib/mysql
      - ./config/mysql/my.cnf:/etc/mysql/conf.d/my.cnf
    ports:
      - "3306:3306"
    networks:
      - io_platform_network

  # Redis缓存
  redis:
    image: redis:7-alpine
    container_name: io_platform_redis
    restart: always
    volumes:
      - redis_data:/data
      - ./config/redis/redis.conf:/etc/redis/redis.conf
    ports:
      - "6379:6379"
    networks:
      - io_platform_network

  # 后端API服务
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: io_platform_backend
    restart: always
    environment:
      FLASK_CONFIG: production
      MYSQL_USER: io_user
      MYSQL_PASSWORD: your-password
      MYSQL_HOST: mysql
      MYSQL_PORT: 3306
      MYSQL_DATABASE: io_platform
      REDIS_HOST: redis
      REDIS_PORT: 6379
      SECRET_KEY: your-secret-key
      JWT_SECRET_KEY: your-jwt-secret-key
    volumes:
      - ./backend/logs:/app/logs
      - ./backend/uploads:/app/uploads
    ports:
      - "5000:5000"
    depends_on:
      - mysql
      - redis
    networks:
      - io_platform_network

  # 前端服务
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: io_platform_frontend
    restart: always
    environment:
      VUE_APP_API_BASE_URL: http://your-domain.com/api
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - io_platform_network

  # Nginx反向代理
  nginx:
    image: nginx:alpine
    container_name: io_platform_nginx
    restart: always
    volumes:
      - ./config/nginx/nginx.conf:/etc/nginx/nginx.conf
      - ./config/nginx/sites-enabled:/etc/nginx/sites-enabled
    ports:
      - "443:443"
      - "80:80"
    depends_on:
      - backend
      - frontend
    networks:
      - io_platform_network

volumes:
  mysql_data:
  redis_data:

networks:
  io_platform_network:
    driver: bridge
```

#### 3.1.3 启动服务
```bash
# 构建并启动所有服务
docker-compose up -d --build

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

### 3.2 手动部署

#### 3.2.1 系统准备
```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装必要的软件
sudo apt install -y python3-pip python3-venv nodejs npm mysql-server redis-server nginx

# 配置防火墙
sudo ufw allow 22    # SSH
sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS
sudo ufw allow 5000  # Backend API
sudo ufw enable
```

#### 3.2.2 数据库配置
```bash
# MySQL安全配置
sudo mysql_secure_installation

# 登录MySQL
sudo mysql -u root -p

# 创建数据库和用户
CREATE DATABASE io_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'io_user'@'localhost' IDENTIFIED BY 'your-password';
GRANT ALL PRIVILEGES ON io_platform.* TO 'io_user'@'localhost';
FLUSH PRIVILEGES;

```

#### 3.2.3 Redis配置
```bash
# 编辑Redis配置文件
sudo nano /etc/redis/redis.conf

# 修改配置
bind 127.0.0.1
protected-mode yes
port 6379

# 重启Redis
sudo systemctl restart redis
sudo systemctl enable redis
```

#### 3.2.4 应用部署
```bash
# 创建应用目录
sudo mkdir -p /opt/io-platform
cd /opt/io-platform

# 克隆代码
sudo git clone https://github.com/your-org/io-performance-platform.git .

# 设置权限
sudo chown -R $USER:$USER /opt/io-platform

# 部署后端
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件

# 初始化数据库
flask db upgrade

# 使用Gunicorn启动
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app --daemon

# 部署前端
cd ../frontend
npm install
npm run build

# 使用Nginx serving静态文件
sudo cp config/nginx/io-platform.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/io-platform.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 4. 配置Nginx

### 4.1 Nginx配置示例
创建 `/etc/nginx/sites-available/io-platform.conf`：

```nginx
# 前端静态文件服务
server {
    listen 80;
    server_name your-domain.com;
    
    # 前端静态文件
    location / {
        root /opt/io-platform/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    # API代理
    location /api {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 86400;
    }
    
    # 健康检查
    location /health {
        proxy_pass http://127.0.0.1:5000/health;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        root /opt/io-platform/frontend/dist;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}

# HTTPS配置（可选）
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    
    ssl_certificate /path/to/your/certificate.crt;
    ssl_certificate_key /path/to/your/private.key;
    
    # SSL配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    
    # 包含上面的location配置
    include /etc/nginx/sites-available/io-platform-locations.conf;
}
```

## 5. 系统服务配置

### 5.1 创建后端服务
创建 `/etc/systemd/system/io-platform-backend.service`：

```ini
[Unit]
Description=IO Performance Platform Backend
After=network.target mysql.service redis.service

[Service]
User=io-user
Group=io-user
WorkingDirectory=/opt/io-platform/backend
Environment=FLASK_CONFIG=production
ExecStart=/opt/io-platform/backend/venv/bin/gunicorn -w 4 -b 0.0.0.0:5000 app:app
ExecReload=/bin/kill -s HUP $MAINPID
KillMode=mixed
TimeoutStopSec=5
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

### 5.2 创建Celery服务
创建 `/etc/systemd/system/io-platform-celery.service`：

```ini
[Unit]
Description=IO Performance Platform Celery Worker
After=network.target mysql.service redis.service

[Service]
User=io-user
Group=io-user
WorkingDirectory=/opt/io-platform/backend
Environment=FLASK_CONFIG=production
ExecStart=/opt/io-platform/backend/venv/bin/celery -A app.celery worker --loglevel=info
ExecReload=/bin/kill -s HUP $MAINPID
KillMode=mixed
TimeoutStopSec=5
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

### 5.3 启动服务
```bash
# 重新加载systemd
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start io-platform-backend
sudo systemctl start io-platform-celery

# 设置开机自启
sudo systemctl enable io-platform-backend
sudo systemctl enable io-platform-celery

# 查看服务状态
sudo systemctl status io-platform-backend
sudo systemctl status io-platform-celery
```

## 6. 安全配置

### 6.1 防火墙配置
```bash
# 配置UFW防火墙
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 允许必要端口
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS

# 限制SSH访问（可选）

# 启用防火墙
```


## 7. 监控和日志

### 7.1 配置日志轮转
创建 `/etc/logrotate.d/io-platform`：

```bash
/opt/io-platform/backend/logs/*.log {
    daily
    missingok
    rotate 30
    compress
    delaycompress
    notifempty
    create 644 io-user io-user
    postrotate
        systemctl reload io-platform-backend
    endscript
}
```

### 7.2 监控脚本
创建监控脚本 `/opt/io-platform/scripts/monitor.sh`：

```bash
#!/bin/bash
# IO Platform监控脚本

# 检查服务状态
check_service() {
    if systemctl is-active --quiet $1; then
        echo "$1: RUNNING"
        return 0
    else
        echo "$1: STOPPED"
        return 1
    fi
}

# 检查端口
check_port() {
    if netstat -tuln | grep -q ":$1 "; then
        echo "Port $1: OPEN"
        return 0
    else
        echo "Port $1: CLOSED"
        return 1
    fi
}

# 执行检查
echo "=== IO Platform Status Check ==="
echo "Timestamp: $(date)"
echo ""

check_service mysql
check_service redis
check_service nginx
check_service io-platform-backend

echo ""
check_port 3306  # MySQL
check_port 6379  # Redis
check_port 80    # HTTP
check_port 5000  # Backend API

echo ""
echo "=== Database Connection Test ==="
mysql -u io_user -p'your-password' -e "SELECT 1;" io_platform 2>/dev/null && echo "Database: OK" || echo "Database: ERROR"

echo ""
echo "=== Redis Connection Test ==="
redis-cli ping 2>/dev/null && echo "Redis: OK" || echo "Redis: ERROR"
```

赋予执行权限：
```bash
chmod +x /opt/io-platform/scripts/monitor.sh
```

## 8. 备份策略

### 8.1 数据库备份
创建备份脚本 `/opt/io-platform/scripts/backup-db.sh`：

```bash
#!/bin/bash
# 数据库备份脚本

BACKUP_DIR="/opt/io-platform/backups"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="io_platform"
DB_USER="io_user"
DB_PASS="your-password"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 执行备份
mysqldump -u $DB_USER -p$DB_PASS $DB_NAME > $BACKUP_DIR/db_backup_$DATE.sql

# 压缩备份文件
gzip $BACKUP_DIR/db_backup_$DATE.sql

# 删除7天前的备份
find $BACKUP_DIR -name "db_backup_*.sql.gz" -mtime +7 -delete

echo "Database backup completed: $BACKUP_DIR/db_backup_$DATE.sql.gz"
```

### 8.2 配置文件备份
```bash
#!/bin/bash
# 配置文件备份脚本

BACKUP_DIR="/opt/io-platform/backups"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR/config

# 备份配置文件
cp -r /opt/io-platform/backend/config $BACKUP_DIR/config/config_$DATE
cp /opt/io-platform/frontend/.env $BACKUP_DIR/config/frontend_env_$DATE

# 压缩备份文件
tar -czf $BACKUP_DIR/config_backup_$DATE.tar.gz -C $BACKUP_DIR config/

# 清理临时文件
rm -rf $BACKUP_DIR/config

# 删除30天前的备份
find $BACKUP_DIR -name "config_backup_*.tar.gz" -mtime +30 -delete

echo "Config backup completed: $BACKUP_DIR/config_backup_$DATE.tar.gz"
```

## 9. 故障排除

### 9.1 常见问题

#### 9.1.1 数据库连接失败
```bash
# 检查MySQL服务状态
sudo systemctl status mysql

# 检查端口是否监听
netstat -tuln | grep 3306

# 检查用户权限
mysql -u root -p -e "SELECT User, Host FROM mysql.user;"
```

```bash

sudo systemctl status redis

# 检查配置文件
sudo nano /etc/redis/redis.conf

redis-cli ping
```

#### 9.1.3 前端无法访问API
```bash
# 检查后端服务状态
sudo systemctl status io-platform-backend

# 检查端口监听
netstat -tuln | grep 5000

# 检查Nginx配置
sudo nginx -t
sudo systemctl status nginx
```
