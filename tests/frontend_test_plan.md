# 前端界面测试计划

## 测试目标

验证前端界面的以下功能：
1. 节点和分区选择功能
2. 数据聚合显示的正确性
3. IO模型名称的动态生成
4. P99时延的显示

## 测试环境

- 前端服务器地址：http://localhost:8081
- 后端服务器地址：http://localhost:5002
- 浏览器：Chrome、Firefox、Edge

## 测试用例

### 1. 节点和分区选择功能测试

#### 测试步骤
1. 登录前端界面
2. 进入任务详情页面
3. 点击"编辑IP信息"按钮
4. 验证分区列表是否正确显示
5. 点击"添加分区"按钮，输入分区名称和路径
6. 验证新分区是否成功添加到列表中
7. 点击"删除"按钮，删除一个分区
8. 验证分区是否成功从列表中删除
9. 点击"保存"按钮，保存分区设置
10. 验证保存是否成功

#### 预期结果
- 分区列表正确显示现有分区
- 新分区成功添加到列表中
- 分区成功从列表中删除
- 分区设置成功保存

### 2. 数据聚合显示的正确性测试

#### 测试步骤
1. 登录前端界面
2. 进入结果详情页面
3. 选择多个节点
4. 选择多个分区
5. 点击"刷新数据"按钮
6. 验证数据表格中的数据是否正确聚合
7. 验证总IOPS和总吞吐量是否为各分区之和
8. 验证平均时延和P99时延是否为各分区的平均值
9. 验证最大时延是否为各分区的最大值

#### 预期结果
- 数据表格正确显示聚合后的数据
- 总IOPS和总吞吐量为各分区之和
- 平均时延和P99时延为各分区的平均值
- 最大时延为各分区的最大值

### 3. IO模型名称的动态生成测试

#### 测试步骤
1. 登录前端界面
2. 进入任务详情页面
3. 点击"编辑IO任务"按钮
4. 修改IO类型、队列深度等参数
5. 验证模型列表是否实时更新
6. 验证IO模型名称是否正确生成
7. 点击"确定"按钮，保存IO任务设置
8. 验证保存是否成功

#### 预期结果
- 模型列表实时更新
- IO模型名称正确生成，格式为"ioType_qdqueueDepth"
- IO任务设置成功保存

### 4. P99时延的显示测试

#### 测试步骤
1. 登录前端界面
2. 进入结果详情页面
3. 选择"详细数据"标签页
4. 选择节点和分区
5. 点击"刷新数据"按钮
6. 验证数据表格中是否显示P99时延列
7. 验证P99时延值是否正确显示
8. 点击"导出数据"按钮，导出数据
9. 验证导出的CSV文件中是否包含P99时延数据

#### 预期结果
- 数据表格中显示P99时延列
- P99时延值正确显示
- 导出的CSV文件中包含P99时延数据

## 测试执行计划

1. **准备测试数据**：确保后端数据库中有测试节点、IO任务和结果数据
2. **启动服务器**：启动前端和后端服务器
3. **执行测试用例**：按照测试用例逐步执行测试
4. **记录测试结果**：记录测试过程中的问题和结果
5. **生成测试报告**：汇总测试结果，生成测试报告

## 测试通过标准

1. 所有测试用例执行成功
2. 功能正常运行，无错误
3. 数据显示正确，符合预期
4. 用户界面响应及时，无明显延迟

## 测试风险

1. 后端数据不足，导致测试无法正常进行
2. 网络连接问题，导致前后端通信失败
3. 浏览器兼容性问题，导致功能在不同浏览器中表现不一致

## 测试注意事项

1. 测试前确保后端服务器正常运行
2. 测试过程中注意观察浏览器控制台，记录错误信息
3. 测试数据应覆盖正常情况和边界情况
4. 测试完成后清理测试数据，避免影响其他测试
