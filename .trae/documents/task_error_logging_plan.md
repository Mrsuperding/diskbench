# 任务执行失败原因记录与返回 - 实现计划

## [x] 任务 1: 修复任务执行失败时的错误信息记录
- **优先级**: P0
- **依赖**: 无
- **描述**:
  - 修改 `run_task_execution` 函数，在任务执行失败时记录具体的错误原因
  - 将硬编码的错误信息替换为实际的错误信息
  - 确保错误信息能够被正确保存到数据库并返回给前端
- **成功标准**:
  - 任务执行失败时，能够记录并返回具体的错误原因
  - 前端能够显示任务失败的具体原因
- **测试要求**:
  - `programmatic` TR-1.1: 任务执行失败时，`execution.error_message` 字段包含具体的错误原因
  - `programmatic` TR-1.2: 前端能够获取并显示任务失败的具体原因
  - `human-judgement` TR-1.3: 错误信息清晰易懂，能够帮助用户快速定位问题
