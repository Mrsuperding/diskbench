核心功能特性

双测试引擎

同时支持fio和vdbench两种主流IO测试工具，满足不同场景的测试需求，提供灵活的测试配置选项。

分布式测试

支持多节点、多分区的并发性能测试，可同时监控多个存储节点的性能表现。

实时监控

提供实时的性能数据监控和可视化展示，支持IOPS、带宽、延迟等关键指标的实时查看。

数据分析

强大的数据分析和可视化功能，支持历史数据对比、性能趋势分析和详细的测试报告生成。

权限管理

完善的用户权限管理体系，支持管理员和普通用户角色，实现细粒度的权限控制。

项目管理

支持任务空间管理，可将测试任务按项目分类，便于团队协作和项目管理。

技术架构

前端技术

  • Vue.js 3 - 渐进式JavaScript框架
  • Element Plus - Vue 3组件库
  • ECharts - 功能强大的图表库
  • Pinia - Vue状态管理
  • Vue Router - 路由管理

后端技术

  • Flask - 轻量级Python Web框架
  • SQLAlchemy - Python ORM工具
  • JWT - 安全的认证机制
  • Celery - 分布式任务队列
  • Redis - 内存数据结构存储

数据库

  • MySQL 8.0 - 关系型数据库
  • Redis - 缓存和消息队列
  • 数据加密 - 敏感信息保护
  • 索引优化 - 查询性能优化
  • 分区策略 - 大数据处理

部署运维

  • Docker - 容器化平台
  • Docker Compose - 容器编排
  • Nginx - 高性能Web服务器
  • 监控告警 - 系统状态监控
  • 安全防护 - 多层安全机制
